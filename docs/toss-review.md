# 앱인토스 심사 제출 자료 — 코인 선물 트레이딩 연습

## 앱 정보
- 표시명(한글 이름): 코인 선물 트레이딩 연습 (appName: blindcandle, 2026-10-12 변경)
- 한 줄 소개: 어느 시점인지 모르는 과거 차트로 매매 감각을 연습해 보는 모의 매매 게임
- 상세 설명: 코인 선물 트레이딩 연습은 날짜와 종목 이름이 가려진 과거 차트를 한 캔들씩 넘기며 가상의 자금으로 매수·매도를 연습하는 서비스입니다. 라운드가 끝나면 실제 시점과 결과가 공개되고, 내 판단이 어땠는지 되돌아볼 수 있습니다. 실제 돈·자산·주문은 사용되지 않습니다.
- 카테고리 제안: 금융 교육 / 게임·연습 (콘솔 선택지에서 가장 가까운 항목)

## 심사 담당자용 설명
- 모의 매매 연습 서비스이며 실제 돈, 실제 자산, 실제 주문이 전혀 없습니다.
- 투자 권유, 종목 추천, 매매 신호, 수익 보장, 경품·보상 제공이 없습니다.
- 시세 원본 데이터를 사용자에게 내려주지 않습니다. 라운드 종료 전에는 실제 시점·가격을 클라이언트에 보내지 않습니다.
- 데이터 출처: 바이낸스 과거 차트(코인).
- 로그인: 토스 로그인 기반 익명 사용자 키(개인 식별 정보 미저장).

3. 매수·매도 주문 패널(가상 자금)
4. 포지션 보유 중 화면
