# 2주차 커뮤니티 게시 (가설 1, 2 검증)

목표: 써본 사람 30명, 그중 5명 이상과 짧은 대화.
원칙: 홍보가 아니라 **피드백 요청**으로 올린다. 수익 보장, 매매 신호, 거래소 레퍼럴 문구는 쓰지 않는다 (PLAN.md 9장).

**규칙: 운영자(방장, 매니저)의 허락을 먼저 받은 곳에만 올린다.** 무료 서비스라도 대형 커뮤니티는 "피드백 요청" 글을 광고로 본다. 게시판 규칙은 Claude가 원문을 확인한 뒤에만 사용자에게 게시를 요청한다.

## 올릴 곳: 허락을 받는 방식

| 순서 | 곳 | 방법 |
|---|---|---|
| 1 | 카카오톡 오픈채팅 "비트코인 선물", "선물 매매" 검색 상위 방 | 방 공지에서 홍보 금지 여부 확인 → 방장에게 1:1로 아래 "허락 요청" 메시지 → 허락하면 짧은 버전 올리기 |
| 2 | 디시 마이너 갤러리 중 선물, 차트 관련 갤러리 | 갤러리 공지에서 홍보 규칙 확인 → 매니저에게 허락 요청 → 허락하면 긴 버전 |
| 3 | 사용자 본인 SNS (X, 스레드) | 본인 계정이라 규칙 문제 없음. 도달은 작음 |
